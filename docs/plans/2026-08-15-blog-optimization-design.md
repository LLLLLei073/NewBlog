# Blog 优化设计

## 目标

在不破坏现有文章阅读体验和深色星空主题的前提下，把站点从通用 Astro 模板提升为有个人辨识度的技术博客，并优先消除公开设备遥测与自动提交带来的隐私、运维风险。

## 方案选择

1. 只做配色和卡片微调：改动小，但无法解决内容模板感与隐私问题。
2. 安全优先的编辑式改版（采用）：停止状态采集与 Git 自动提交，首页改为重点文章、近期更新和主题索引的非对称布局，关于页改为作者与博客说明。
3. 全量品牌重构：同时替换所有列表页、文章页和字体资源，风险与改动面过大，不适合当前脏工作区和异常 Git 历史。

## 信息架构

- 首页：左侧品牌主张与站点简介，右侧显示文章总数和主题数；正文以一篇重点文章为视觉中心，旁边排列近期文章；底部以紧凑主题索引替代五张等宽卡片。
- 关于页：作者简介、关注主题、写作原则、站点技术信息与可验证的公开入口。删除设备、窗口、硬件、时间轴和活动统计。
- 友链页：没有真实数据时显示明确的邀请与交换规则，不再发布 `example.com` 占位内容。
- 文章页：保留现有三栏阅读结构，补齐键盘可用的图片灯箱和文章级分享元数据。

## 隐私与数据流

- `public/status.json` 仅保留无个人数据的停用说明。
- `status-watcher.ps1` 改为安全停用入口，不再读取前台窗口、硬件或执行 Git 命令。
- watchdog 与安装脚本改为明确停用，避免未来误开启旧流程。
- 不重写 Git 历史、不执行 force push；历史清理留作单独、有备份的维护任务。

## 视觉方向

采用“深空中的个人技术刊物”：保留暖橙与暗色氛围，但降低卡片重复感。标题使用中文衬线字体栈，正文使用人文无衬线字体栈；布局通过大标题、细分隔线、编号和不对称留白建立节奏。动画尊重 `prefers-reduced-motion`。

## 验证

- `npm run build` 无错误，修复既有 CSS 与 Astro 配置弃用警告。
- 检查生成页 canonical、文章 `og:type=article`、404 `noindex`。
- 本地浏览器验证 1440px、375px、320px，无横向溢出，导航和灯箱支持键盘。
- 扫描生成站点的内部链接与公开状态 JSON，确认无敏感字段。
