# 三维书房（本地开发版）

## 范围与来源

仅 `/room/` 改为 Three.js 实体场景；首页仍使用原插画，阅读页不变。房间、家具和小煤球用代码建模，人物使用一份有骨骼的 VRM，不再使用人物动作图集与前景遮挡蒙版。

- 发色、上衣及下装颜色由 `character3d.ts` 在运行时调整，原模型文件未改写。外观接近首页的深发、便服方向，但不是首页人物的精确三维复刻。
- `@pixiv/three-vrm` 处理官方模型的服装骨骼约束、MToon 材质和头发弹簧骨骼；使用已有 Three.js，不引入 React。官方运行库采用 MIT 许可，模型许可独立于代码许可。

## 动作与场景

`motion3d.ts` 以米为单位定义路线、椅面和起身点。移动时长从路线长度计算，步态相位从累计移动距离计算；双腿使用双骨骼 IK，支撑期脚部反向位移抵消躯干前进。起身时身体向椅面前方移动，双脚维持前方支点，坐下逆向返回。手部朝书本放置。

这是一套预设路线和程序骨骼动作，不是动作捕捉，也不支持任意寻路或自由镜头。家具与人物使用真实深度遮挡，站立、行走和坐姿使用同一模型。两个角色不参与物品点击；桌面热点投影自三维物品坐标，手机保留下方九个普通入口。小煤球可见宽度按桌面 40px、手机 32px 调整，点击区至少 44px。

沿用共享的暂停和台灯偏好，光照按设备本地时间计算。窗口方向光、环境光和台灯各自作用于三维场景；阅读主题不受影响。绘制上限 30fps，DPR 上限 1.5，绘制宽度上限 1500px。隐藏页面停止渲染；离开页面释放几何体、材质、纹理和渲染器。初始化时显示简洁的加载提示；WebGL 失败时显示文字提示，保留普通入口及搜索。旧房间插画已从发布资源中删除，不再闪现。

## 验收方式

- `npm test`：构建并检查 19 个页面、搜索、首页光照及三维路线。
- `npm run format:check`；TypeScript 检查入口 `src/components/room/life.ts`。
- `tests/fixtures/room3d.html`：时刻、灯光和动作位置验收，可连续播放三个循环；仅临时复制到 `public/__room3d.html` 用开发服务器检查，构建前移除副本。
- `tests/fixtures/room-lifecycle.html`：对实际 `/room/` 注入 WebGL/模型失败及减少动态效果，检查暂停、后台、页面缓存恢复和上下文恢复；同样不随站点发布。

当前原始插画 PNG 留在 `docs/art/room/` 作为历史素材来源；旧动作图、法线图和遮挡图不再进入房间运行时。实体手机性能与耗电未实测，桌面浏览器窄屏检查不能代替真机测试。本地验收完成后，按用户要求发布。

## 本地验收记录（2026-09-16）

- 最终构建生成 19 个页面，24 项测试全部通过；格式检查、TypeScript 和 `git diff --check` 通过。
- 实际浏览器检查正午、清晨、黄昏及午夜，台灯自动和手动开关可见局部照明变化。检查坐姿、起身与行走；验收页以正常时间推进完成三个循环（约 131 秒，停留缩短至 6 秒）。
- 1440px 桌面及 375px、320px 窄屏检查；320px 时文档可用宽度和滚动宽度均为 312px，九个入口保留，煤球点击区域为 44px。搜索面板位于场景下方，命中、无结果推荐、Escape 关闭及焦点返回通过。
- 生命周期最终复测：焦点、鼠标进入、触摸按下均停止煤球移动；1.1 秒采样窗口暂停和后台绘制调用增量均为 0，恢复后继续绘制；pagehide、页面缓存返回和 WebGL 上下文恢复通过。
- 无 WebGL 和模型请求失败均保留文字提示、九个入口和搜索；减少动态效果时按钮禁用，角色不循环活动。
- 已在独立构建预览 `http://127.0.0.1:4652/room/` 确认三维场景加载，并实际点击煤球打开搜索。验收夹具的 public 临时副本已移除。
- 模型约 10.3 MiB，房间按需加载的三维 JS 约 754 KB（未压缩传输大小）；首页不加载该模块。初次加载成本高于旧图集，真机性能仍待实测。
