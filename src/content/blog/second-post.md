这篇文章展示博客支持的 Markdown 语法。

## 标题

你可以使用 `#` 到 `######` 创建不同级别的标题。

## 列表

无序列表：

- 第一项
- 第二项
- 第三项

有序列表：

1. 第一步
2. 第二步
3. 第三步

## 代码块

支持语法高亮：

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"
```
